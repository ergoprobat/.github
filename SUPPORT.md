# Getting help

- **Questions and ideas:** [GitHub Discussions in ipso](https://github.com/ipsofacto-io/ipso/discussions). For the EDR format, use the [edr-spec discussions](https://github.com/ipsofacto-io/edr-spec/discussions).
- **Bugs and feature requests:** open an issue in the repository concerned, using its issue forms.
- **Security vulnerabilities:** follow the [security policy](https://github.com/ipsofacto-io/.github/blob/main/SECURITY.md).
- **Commercial support:** available from the private beta onwards; details will be published here.
